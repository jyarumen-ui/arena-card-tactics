# アリーナ・カードタクティクス

2列×3段の盤面にモンスターを配置して戦う、ブラウザで動くターン制カードバトルゲームです。
インストール不要。**PC・タブレット・スマホ（横向き）**で遊べます。

## 遊び方

1. **リーダーを選ぶ**（8職業。それぞれ専用の必殺技と専用カードがあります）
2. **マリガン**で初手を引き直す
3. 手札をタップ → **光るマス**をタップで召喚
4. **緑枠のユニット**をタップ → **赤く光る相手**をタップで攻撃
5. 相手リーダーのHPを0にすれば勝ち

取り消しは「✕やめる」ボタンかESCキー。カードをタップすると左下に詳細が出ます。

## 主なルール

- MPは毎ターン1ずつ増えて最大10。デッキ30枚、同名2枚まで（レジェンドは1枚）
- **前衛・後衛**：同じ段の前衛がいる間、その後ろの後衛は攻撃されません
- **ウォール**：相手の前衛3マスが全部埋まると、リーダーを攻撃できません
- **テンション**：MP1を払って1ターン1回ためられ、3で職業ごとの必殺技が発動
- 特性は19種（におうだち／速攻／ステルス／ねらい撃ち／貫通／超貫通／2回攻撃／メタルボディ／毒／テンションリンク／スキルブースト／攻撃時／おうえん／絶好調／封印 ほか）

## 収録内容

| | |
|---|---|
| カード | 118種（ノーマル／レア／スーパーレア／レジェンド） |
| 職業 | 8種（それぞれ専用の必殺技・専用カード） |
| モード | AI対戦（弱い／ふつう／強い）、2人交代対戦 |
| その他 | カードパック、錬金（分解・生成）、デッキ編成、デイリーミッション |

## バランス

AI同士の自動対戦を **9,600試合** 走らせて調整しています。

- 先攻勝率 **49.5%**
- 8職業の勝率差 **3.2ポイント**
- 平均決着 **9.2ラウンド**

## 技術メモ

- **依存ライブラリなし。HTML 1ファイルで動きます**（`arena-card-tactics.html` は画像も内蔵した単体版）
- モンスターと職業のイラストは生成AIで作成したオリジナル（31点）
- BGMと効果音は WebAudio による合成音（音声ファイルなし）
- セーブはブラウザのローカル保存。ホーム画面から書き出し／読み込みで端末間の引き継ぎができます

## ファイル

- `index.html` … 開発版（`art/` フォルダの画像を読み込みます）
- `arena-card-tactics.html` … 画像を内蔵した単体版。これ1つで動きます
- `art/` … イラスト31点
- `build-standalone.py` … 単体版を生成するスクリプト

## ライセンス・注意

ゲームシステムはボード配置型カードバトルの一般的なルールを参考にした独自実装で、
**カード名・イラスト・音楽はすべてオリジナル**です。既存作品の名称・画像・音源は一切使用していません。
